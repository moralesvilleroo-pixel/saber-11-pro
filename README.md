# Saber11 Pro

Plataforma para preparar el examen ICFES Saber 11 en Web, Android y Windows, basada en práctica de
recuperación con retroalimentación por opción, repetición espaciada FSRS-6 y práctica intercalada.

- Reglas para desarrollar: [CLAUDE.md](CLAUDE.md)
- Reglas pedagógicas: [docs/PRD_PEDAGOGIA.md](docs/PRD_PEDAGOGIA.md)
- Estado y siguiente paso: [docs/ESTADO_PROYECTO.md](docs/ESTADO_PROYECTO.md)

Todas las preguntas del banco son originales. Este proyecto no reproduce ítems del Icfes.
